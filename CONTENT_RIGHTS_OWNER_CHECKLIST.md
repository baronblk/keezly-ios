# Content Rights — for the owner to confirm

**Not submitted on the owner's behalf.** Apple asks whether the app contains,
shows or accesses third-party content, and the answer is a declaration in the
owner's name.

Current state in App Store Connect: `contentRightsDeclaration` is **null** —
unanswered, and required before submission.

---

## Proposed answer

**"No third-party content"** — Apple's
`DOES_NOT_USE_THIRD_PARTY_CONTENT`.

---

## The evidence, item by item

| Part of the app | Where it comes from | Third-party rights? |
|---|---|---|
| The rules of Keezen | A traditional folk game, played in the Netherlands and Germany for generations. Not owned by anybody | No |
| The engine | Written for this project — `Packages/KeezlyCore` | No |
| The interface | Written for this project — `App/Keezly` | No |
| Board and piece artwork | Drawn in code. `BoardGeometry`, `BoardSurface`, `PawnView`, `SuitGlyph` — there is no imported image of a board or a piece | No |
| App icon | Generated from source by `Tools/` and checked by `scripts/icon-check.sh` | No |
| Card faces | Drawn in code from rank and suit. No card deck image is bundled | No |
| The seven sounds | Synthesised by `Tools/soundforge.py` — modal synthesis, no samples, nothing downloaded | No |
| Achievement artwork | Generated by `Tools/achievementart.py` from the board's own design language | No |
| All text, three languages | Written for this project, in `Localizable.xcstrings` and `fastlane/metadata/` | No |
| Typeface | The system font. Apple's, used as Apple provides it | No |
| Dependencies | **None.** The only package is `KeezlyCore`, in this repository | No |

### Nothing is bundled that was not made here

Every binary asset in the app is generated from source in this repository:

```
App/Keezly/Sounds/*.caf      ← Tools/soundforge.py
App/Keezly/Assets.xcassets   ← colours and the generated icon
build/achievements/*.png     ← Tools/achievementart.py
```

There is no sample library, no stock image, no font file, no clip art, no
downloaded asset and no code copied from another project.

### The name

"Keezen" and "Keezenspel" are the common names of the traditional game. "Keezly"
is this project's own. The owner should satisfy himself that no trade mark
conflict exists in the territories he sells in — that is a question about
registers, not about the code, and nothing in this repository can answer it.

## Game Center

Game Center is Apple's service, used through Apple's own framework as Apple
intends. It is not third-party content.
